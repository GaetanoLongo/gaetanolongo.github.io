partOf: "pan-brioche"
tags: ["leavened", "savoury"]
ingredients:
  - { q: "250 g (9 oz)", i: "Manitoba flour (or American flour)" }
  - { q: "250 g (9 oz)", i: "Type 0 flour" }
  - { q: "250 g (9 oz)", i: "Milk" }
  - { q: "80 g (2¾ oz)", i: "Butter" }
  - { q: "40 g (1½ oz)", i: "Sugar" }
  - { q: "15 g (½ oz)", i: "Fresh yeast" }
  - { q: "10 g (⅓ oz)", i: "Salt" }
  - { q: "3", i: "Egg yolks" }
---

1. Mound the flour on the work surface and add the other ingredients in the centre. Knead for at least 20 minutes, until you have a well combined mixture.
2. Put the dough in a container and let it rise for 2 hours in a warm place (20-25 °C / 68-77 °F).
3. Take the dough back, put it on the floured work surface, knock it back well and fold it, shape it into a ball and put it in a buttered and floured cylindrical panettone mould. Let it rise until the mould is completely full.
4. Bake in the oven at 180 °C (355 °F) for about 45 minutes.
5. Let it cool, then wrap it in cling film and keep it in the fridge for at least 24 hours before slicing and filling it.
