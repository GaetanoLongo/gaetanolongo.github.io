  - { q: "100 g (3½ oz)", i: "Fresh brewer's yeast" }
  - { q: "400 g (14 oz)", i: "Cheese, as you like (200 g / 7 oz Parmigiano Reggiano and 200 g / 7 oz pecorino)" }
  - { q: "100 g (3½ oz)", i: "Butter" }
  - { q: "150 g (5¼ oz)", i: "Oil" }
  - { q: "26 g (0.9 oz)", i: "Salt" }
  - { q: "5 g (0.2 oz)", i: "Pepper" }
---

1. Crumble the yeast with a little of the flour and put all the ingredients together.
2. Mix well until you have a dough, pour it into the panettone-style mould and let it rise.
3. Bake in an already hot oven, at 170 °C (340 °F), for about an hour.
4. Never open the oven, at least for the first half hour. Check the cooking by piercing it with a wooden skewer: if it comes out dry, it is ready.
5. Let it cool before tasting.

> Enjoy!
