---
title: "Blueberry cheesecake"
description: "Baked ricotta cheesecake served with warm blueberry sauce."
date: 2026-11-16
cook: "1 hour"
oven: "160 °C (320 °F)"
tags: ["desserts", "cakes"]
ingredients:
  - { q: "500 g (1.1 lb)", i: "Ricotta" }
  - { q: "170 g (6 oz)", i: "Cane sugar (120 g / 4¼ oz in the batter, the rest for the sauce)" }
  - { q: "200 g (7 oz)", i: "Blueberries" }
  - { q: "3", i: "Eggs" }
  - { q: "1", i: "Lemon" }
  - { q: "3 tbsp", i: "Cornstarch" }
---

1. Mix the ricotta with 120 g (4¼ oz) of the sugar.
2. Add the 3 egg yolks one at a time, then the cornstarch and the lemon juice.
3. When the mixture is smooth, fold in the egg whites, whipped to stiff peaks.
4. Pour into a rectangular pan and bake at 160 °C (320 °F) for 1 hour.
5. Meanwhile, blend the blueberries with the remaining sugar.
6. Serve the cake with the blueberry sauce, warm.
