title: "Crescia di Pasqua, versione 1"
description: "Pizza al formaggio: un grande impasto lievitato con 10 uova e 400 g di formaggio."
date: 2026-11-16
cook: "circa 1 ora"
oven: "170 °C"
partOf: "crescia-di-pasqua"
tags: ["pasqua", "lievitati", "salati"]
ingredients:
  - { q: "1 kg", i: "Farina" }
  - { q: "10", i: "Uova" }
  - { q: "100 g", i: "Lievito di birra" }
  - { q: "400 g", i: "Formaggio, a piacere (200 g di Parmigiano Reggiano e 200 g di pecorino)" }
  - { q: "100 g", i: "Burro" }
  - { q: "150 g", i: "Olio" }
  - { q: "26 g", i: "Sale" }
  - { q: "5 g", i: "Pepe" }
---

1. Sfarinare il lievito con un po' di farina e mettere insieme tutti gli ingredienti.
2. Amalgamare per bene fino a ottenere un impasto, versarlo nello stampo tipo panettone e lasciarlo lievitare.
3. Infornare in forno già caldo, a 170 °C, per circa un'ora.
4. Non aprire mai il forno, almeno per la prima mezz'ora. Controllare la cottura infilzando uno spiedino di legno: se risulta asciutto, è pronta.
5. Lasciare raffreddare prima di assaggiarla.

> Buon appetito!
