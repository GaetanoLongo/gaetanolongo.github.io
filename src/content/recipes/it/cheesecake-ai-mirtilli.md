---
title: "Cheesecake ai mirtilli"
description: "Cheesecake di ricotta cotta in forno, servita con salsa di mirtilli tiepida."
date: 2026-11-16
cook: "1 ora"
tags: ["dolci", "torte"]
ingredients:
  - { q: "500 g", i: "Ricotta" }
  - { q: "170 g", i: "Zucchero di canna (120 g nell'impasto, il resto per la salsa)" }
  - { q: "200 g", i: "Mirtilli" }
  - { q: "3", i: "Uova" }
  - { q: "1", i: "Limone" }
  - { q: "3 cucchiai", i: "Maizena" }
---

1. Lavorare la ricotta con 120 g di zucchero.
2. Incorporare uno alla volta i 3 tuorli, poi la maizena e il succo del limone.
3. Quando il composto è omogeneo, incorporare gli albumi montati a neve.
4. Versare in uno stampo rettangolare e cuocere a 160 °C per 1 ora.
5. Nel frattempo frullare i mirtilli con lo zucchero rimasto.
6. Servire il dolce con la salsa di mirtilli tiepida.
