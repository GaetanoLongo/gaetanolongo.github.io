ingredients:
  - { q: "250 g", i: "Farina Manitoba (o farina americana)" }
  - { q: "250 g", i: "Farina 0" }
  - { q: "250 g", i: "Latte" }
  - { q: "80 g", i: "Burro" }
  - { q: "40 g", i: "Zucchero" }
  - { q: "15 g", i: "Lievito di birra" }
  - { q: "10 g", i: "Sale" }
  - { q: "3", i: "Tuorli" }
---

1. Mettere la farina a fontana sulla spianatoia e aggiungere al centro gli altri ingredienti. Impastare per almeno 20 minuti, fino a ottenere un composto ben omogeneo.
2. Mettere l'impasto in un contenitore e lasciarlo lievitare per 2 ore in un luogo caldo (20-25 °C).
3. Riprendere la pasta, metterla sulla spianatoia infarinata, sgonfiarla bene e ripiegarla, fare una palla e metterla in uno stampo cilindrico da panettone imburrato e infarinato. Lasciare lievitare fino a riempire completamente lo stampo.
4. Cuocere in forno a 180 °C per circa 45 minuti.
5. Lasciare raffreddare, poi avvolgere nella pellicola e conservare in frigorifero almeno 24 ore prima di affettarlo e farcirlo.
