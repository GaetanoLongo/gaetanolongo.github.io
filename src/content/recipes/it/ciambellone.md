description: "Ciambellone marmorizzato al cacao: l'impasto resta piuttosto liquido, ed è questo il segreto della sua morbidezza."
date: 2026-11-16
cook: "40 min"
oven: "180 °C, statico"
tags: ["dolci", "torte"]
ingredients:
  - { q: "250 g", i: "Zucchero" }
  - { q: "250 g", i: "Farina 00" }
  - { q: "130 g", i: "Acqua" }
  - { q: "130 g", i: "Olio" }
  - { q: "3", i: "Uova" }
  - { q: "1 bustina", i: "Lievito" }
  - { q: "2 cucchiai", i: "Cacao amaro" }
  - { q: "a piacere", i: "Vanillina o aromi" }
---

1. Mettere nel robot le uova e sbatterle con lo zucchero fino a farle diventare spumose. Aggiungere l'olio, l'acqua, il rum (facoltativo), la farina e infine il lievito. Se si vuole, aggiungere anche l'uvetta infarinata.
2. Imburrare uno stampo a ciambella e versarvi i ¾ dell'impasto.
3. Nell'impasto rimasto mescolare bene i 2 cucchiai di cacao amaro, poi versarlo nello stampo sull'impasto bianco.
4. Fare dei cerchi concentrici con un coltello, per ottenere l'effetto marmorizzato.
5. Cuocere in forno statico caldo a 180 °C per circa 40 minuti. Verificare la cottura con la prova dello stecchino.

**Consigli**

- Alla fine l'impasto risulterà piuttosto liquido: non aggiungere altra farina. È proprio così che deve venire, ed è il segreto della sua morbidezza.
- A scelta si possono aggiungere scorza di limone grattugiata, rum, gocce di cioccolato, uvetta.
- Se si mette il latte al posto dell'acqua il risultato non è lo stesso.
