ingredients:
  - { q: "50 g", i: "Lievito di birra (per il lievito)" }
  - { q: "120 ml", i: "Latte (per il lievito)" }
  - { q: "½ cucchiaino", i: "Zucchero (per il lievito)" }
  - { q: "5", i: "Uova" }
  - { q: "q.b.", i: "Sale e pepe" }
  - { q: "50 g", i: "Burro o margarina" }
  - { q: "50 g", i: "Strutto" }
  - { q: "50 g", i: "Olio di semi di girasole" }
  - { q: "500 g", i: "Farina Manitoba" }
  - { q: "120 g", i: "Parmigiano grattugiato" }
  - { q: "120 g", i: "Pecorino romano" }
  - { q: "200 g", i: "Pecorino fresco (facoltativo)" }
---

1. Sciogliere il lievito nel latte tiepido con lo zucchero e lasciar lievitare per circa mezz'ora.
2. Versare in una ciotola gli ingredienti dalle uova al pecorino romano, nell'ordine in cui sono elencati, e infine il lievito sciolto nel latte. Mescolare. Gli ingredienti liquidi con il sale devono venire a contatto con il lievito solo al momento di mescolare.
3. Aggiungere il pecorino fresco a pezzetti (facoltativo).
4. Ungere lo stampo tipo panettone, versare l'impasto e posizionare lo stampo sulla griglia più bassa del forno. Non spostare più lo stampo dal forno e lasciar lievitare dalle 2 alle 4 ore.
5. Cottura: impostare il forno a 50 °C e accendere il grill. Raggiunti i 50 °C, alzare la temperatura a 170-180 °C e impostare la cottura normale, sopra e sotto. Raggiunta la temperatura di cottura, cuocere ancora per 1 ora.
