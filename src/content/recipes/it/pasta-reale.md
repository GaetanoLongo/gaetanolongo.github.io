---
title: "Pasta reale (spugnette)"
description: "Piccoli dadini di uovo, semolino e parmigiano, cotti in un sacchetto e poi nel brodo di carne."
date: 2026-11-16
cook: "circa 1 ora"
tags: ["primi", "brodo"]
ingredients:
  - { q: "1", i: "Uovo" }
  - { q: "1 cucchiaio", i: "Semolino" }
  - { q: "1 cucchiaio", i: "Parmigiano" }
  - { q: "q.b.", i: "Sale, pepe e noce moscata" }
  - { q: "facoltativa", i: "Scorza di limone" }
---

1. Impastare fino a ottenere un composto cremoso.
2. Metterlo in un apposito sacchetto, chiuderlo e farlo bollire nel brodo di dado per circa 1 ora.
3. Tagliare a dadini e cuocere nel brodo di carne.

Si possono congelare.
